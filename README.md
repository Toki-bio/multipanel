# Multipanel

[View site](index.html)

WeGene-derived trait/SNP panel work and related array design materials, plus other panels as the project expands.

Content is behind a simple client-side security-question gate on `index.html` ("Our sysadmin's name"). This is an access gate, not real security — anyone can view page source or fetch files under `wegene/` and `wegene-interface/` directly by URL. Do not put private genotype or personally identifying data in this repo.
